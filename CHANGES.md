# FindSync v2 changes

- Student and staff portals are both mandatory.
- Student registration, login, own lost/found reports, safe matches, claim requests, and status tracking.
- Staff review, approval/rejection, separate physical release, CSV ETL, analytics and audit.
- Server-side authorization, PHP sessions, CSRF, password hashes, ownership checks.
- SQL tables revised for users, claim requests, and unique releases.
- API contract, test plan, demo flow, priorities and definition of done updated.
- Existing `index.html` is unchanged starter reference code; OpenCode must rebuild it, not treat it as the finished PHP app.
